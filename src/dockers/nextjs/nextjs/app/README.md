**location ที่ต้องใส่:**
- `landingpage/` อันนี้เป็นตำแหน่งของโฟลเดอร์ auth ครับ ที่ `src/dockers/nextjs/saves/src/app/auth` เนื้อหาข้างในจะมีโฟลเดอร์เหมือนกัน สามารถลองทับไฟล์เดิมได้แล้วลองดูว่าได้ไหม? ติดอะไรตรงไหน?
- `img/` ล่าสุดเห็นตำแหน่งเก็บรูปภาพอยู่ที่ `src/dockers/nextjs/saves/src/public` ถ้ายังใช้ตำแหน่งเก็บไฟล์นี้อยู่สามารถนำเนื้อหาไฟล์ใน img ทับไปได้เลยครับ
- `style.css` อันนี้ไม่ทราบเหมือนกันว่าปัจจุบันเรียกใช้หรือไม่ และอยู่ที่ตรงไหน
    - ถ้าใช้อยู่แล้วให้ทับไฟล์ style.css เดิมได้เลยครับ 
    - ถ้ายังไม่มีการเรียกใช้ให้ใส่ไฟล์ในตำแหน่งเดียวกับ global.css ที่ `src/dockers/nextjs/saves/src/app` และเขียนโค้ด import ในไฟล์เดียวกันด้วย

**ไฟล์ที่ต้องตรวจสอบ:**

    - ถ้าไม่ใช้แล้ว ให้นำโค้ด background ไปใส่ใน `layout.tsx` ที่อยู่ในตำแหน่งเดียวกันแทนครับ แล้วลบไฟล์นี้ออก

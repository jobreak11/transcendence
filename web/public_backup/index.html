02 // GAME ENGINE

Physics Engine & Real-Time Sync Loop

Deterministic Client-Server Game Loop

To ensure zero latency cheating and synchronized gameplay across remote clients, the game loop operates on a Server-Authoritative Physics Model with client-side prediction and linear interpolation.

game-loop-engine.ts — Server Physics Loop (60 Hz) TypeScript 
// Server-Authoritative 60 FPS Game Loop
const TICK_RATE = 1000 / 60; // 16.66ms tick

export class PongEngine {
    private ball = { x: 400, y: 200, dx: 5, dy: 3, radius: 8 };
    private paddleLeft = { y: 150, height: 80 };
    private paddleRight = { y: 150, height: 80 };

    public updateGameState(inputs: PlayerInputs): GameState {
        // 1. Process Client Input Commands
        this.paddleLeft.y = Math.max(0, Math.min(320, inputs.leftY));
        this.paddleRight.y = Math.max(0, Math.min(320, inputs.rightY));

        // 2. Physics & Collision Detection
        this.ball.x += this.ball.dx;
        this.ball.y += this.ball.dy;

        // Bounce Top/Bottom Walls
        if (this.ball.y <= 0 || this.ball.y >= 400) {
            this.ball.dy *= -1;
        }

        // Left Paddle Collision
        if (this.ball.x <= 25 && this.ball.y >= this.paddleLeft.y && this.ball.y <= this.paddleLeft.y + 80) {
            this.ball.dx = Math.abs(this.ball.dx) * 1.05; // Speed boost
            this.ball.dy += (this.ball.y - (this.paddleLeft.y + 40)) * 0.1;
        }

        // Broadcast State Snapshot over WebSockets
        return this.serializeState();
    }
}

07 // LESSONS

Engineering Challenges & Solutions

CHALLENGE #1: Eliminating Real-Time WebSocket Latency in Pong +

Problem: High ping spikes caused paddle rubber-banding and ball desynchronization during fast-paced multiplayer rallies.

Solution: Implemented client-side extrapolation and snapshot interpolation. The server sends 60 Hz state updates while the client predicts local paddle movement immediately.

CHALLENGE #2: Enforcing True SPA (Single-Page Application) Routing +

Problem: Navigating between chat, game, profiles, and settings without triggering browser page reloads.

Solution: Constructed a custom lightweight Vanilla JS History API Router with dynamic DOM component swapping and state preservation.

CHALLENGE #3: Single-Service Container Constraints in Docker +

Problem: Strict 42 evaluation rules prohibit running multiple services (like Nginx + Node) inside a single container.

Solution: Architected a clean Docker Compose file separating Nginx proxy, Express backend, and PostgreSQL database into 3 distinct containers on a bridge network.
